Drop optional assets here (all are picked up automatically when present):

- `backdrop.jpg`  - painted night-city view for the window (replaces the procedural buildings)
- `music/*.mp3`   - pass one with `--music` (Envato track)
- `sfx/whoosh.*`, `sfx/pop.*` - pass the folder with `--sfx-dir`

Large media is not committed (see .gitignore); keep it on the PC.
